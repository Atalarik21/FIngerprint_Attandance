TOLERANSI WAKTU ABSENSI
Atur batas waktu scan fingerprint yang diperbolehkan.
Masuk: karyawan boleh scan dari (jadwal − X menit) hingga (jadwal + Y menit). Jika melebihi Y menit → TERLAMBAT.
Pulang: karyawan boleh scan dari (jadwal − A menit) hingga (jadwal + B menit).
Contoh: Masuk jam 08:00, sebelum=10, sesudah=0 → scan diterima jam 07:50–08:00 saja

◆ INFO MODE AP (WiFi SETUP)
Mode AP tidak otomatis aktif saat WiFi terputus.
Untuk mengkonfigurasi WiFi baru:
1. Pastikan ada karyawan dengan status Admin.
2. Saat WiFi putus, tekan [*] → [#] di keypad untuk halaman 2.
3. Pilih 7. Mode AP → tempel jari Admin → portal WiFi aktif.
4. Hubungkan HP ke WiFi ABSENSI-SETUP → buka 192.168.4.1.
AP auto-off setelah 5 menit tidak digunakan atau tekan [*].
RESET STATUS KARYAWAN
Jika karyawan lupa scan pulang/kembali istirahat kemarin, admin dapat mereset statusnya agar dapat absensi normal kembali tanpa harus menggunakan Darurat.
